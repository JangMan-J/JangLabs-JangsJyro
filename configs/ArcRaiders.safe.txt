#   ADS gyro — GYRO_ON = ZL (gyro on while LT held), Aim Layer precision on ZL+L3 (L.2/G.10),

# TEST LIVE:
#   1. Movement (WASD), jump (S=Space), lean/crouch (E=LAlt).
#   2. Fire (ZR=LMB), ADS (ZL=RMB).
#   3. Gyro: aim at a distant target. If sensitivity is wrong, tune GYRO_SENS
#      and IN_GAME_SENS together (G.3 requires empirical calibration).
#   4. ADS gyro: hold ZL → gyro activates (+ RMB). Release ZL → gyro stops.
#   5. Aim Layer: hold L3 while ZL held → gyro switches to precision settings.
#   6. L3 tap → RShift; L3 hold → LShift (sprint/walk — only meaningful without ZL).
#   7. R3 tap → C (equip); R3 hold → LCtrl.
#   8. W tap → E (use/interact); W hold → R (reload).
#   9. N tap → F (pick up); N hold → X (alt-use).
#  10. PLUS tap → Tab (scoreboard); PLUS hold → M (map).

# ── Gyro ──────────────────────────────────────────────────────────────────────

# Gyro-on trigger: gyro active only while ZL (LT) is held — ADS gyro.
# G.7 ratchet (L1 + ZR) not needed; gyro is off by default between ZL presses.

# ── Left stick ────────────────────────────────────────────────────────────────
